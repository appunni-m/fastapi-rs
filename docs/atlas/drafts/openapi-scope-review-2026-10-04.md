# OpenAPI scope review (draft, 2026-10-04)

**Status:** source and mapping audit only. No active metadata, atlas, recipe, generated artifact, manifest, or runtime changes. This draft does not claim FastAPI-RS parity.

## Reviewed facts

### Identity and scope

The checked-out FastAPI oracle is 0.141.1 at `95f8322ee1dcda7ceace7b1c4f6c9915b36d748f`; the checked-out Starlette oracle is 1.6.0 at `4f250d6b814587e20c5365f0a5f0c4d42bcb929f`. These match the project pins. Starlette 1.6.0 owns generic response/ASGI behavior; Starlette-RS 0.1.0 at `a345f8c3f5306dbc00c5fc37f8f16d2e79666065` is the target-side generic contract. The OpenAPI document, route-to-document projection, and HTML template logic described below are FastAPI-owned; Pydantic 2.13.4 / pydantic-core 2.46.4 own generated OpenAPI model constructor, validation, and field behavior.

`tests/fixtures/manifest.yaml:/api_surface_contract` has **247** `scope-review-pending` symbol rows under `fastapi.openapi.*`: 241 in `models`, four in `docs`, and two in `utils`. `fastapi.applications.FastAPI.openapi` is `slice-described`, but its behavior state still says full compatibility pending and it has no input or identity workflow. Thus the app method is included below as a FastAPI-owned entry point, not counted among those 247 pending module rows. Private `FastAPI.setup()` is the source-level registration path for the public HTTP endpoints; it is not a public OpenAPI symbol row.

### Signatures and behavior in pinned source

- `fastapi.openapi.utils.get_openapi(*, title: str, version: str, openapi_version: str = "3.1.0", summary: str | None = None, description: str | None = None, routes: Sequence[BaseRoute | routing.RouteContext], webhooks: Sequence[BaseRoute | routing.RouteContext] | None = None, tags: list[dict[str, Any]] | None = None, servers: list[dict[str, str | Any]] | None = None, terms_of_service: str | None = None, contact: dict[str, str | Any] | None = None, license_info: dict[str, str | Any] | None = None, separate_input_output_schemas: bool = True, external_docs: dict[str, Any] | None = None) -> dict[str, Any]` is keyword-only (`fastapi/openapi/utils.py:585-679`). It traverses both routes and webhooks, derives definitions and security schemes, conditionally inserts metadata/components/tags/external docs, always sets `paths`, then validates through `OpenAPI(**output)` and encodes with `by_alias=True, exclude_none=True` (`:620-679`). Falsy optional metadata is omitted by its `if` checks. This result is a document mapping, not a set of directly instantiated `Operation` or `PathItem` instances.
- `fastapi.openapi.utils.generate_operation_id(*, route: routing._APIRouteLike, method: str) -> str` is deprecated at each call with `FastAPIDeprecationWarning` and message “fastapi.openapi.utils.generate_operation_id() was deprecated, it is not used internally, and will be removed soon”; it returns `route.operation_id` when truthy, otherwise delegates to `fastapi.utils.generate_operation_id_for_path(name=route.name, path=route.path_format, method=method)` (`utils.py:266-278`). `get_openapi_operation_metadata` instead uses `route.operation_id or route.unique_id`; it warns on duplicate IDs with a `UserWarning` and endpoint-specific message (`utils.py:287-308`).
- Public docs helpers are keyword-only except the redirect helper: `get_swagger_ui_html(*, openapi_url: str, title: str, swagger_js_url="https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui-bundle.js", swagger_css_url="https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui.css", swagger_favicon_url="https://fastapi.tiangolo.com/img/favicon.png", oauth2_redirect_url: str | None=None, init_oauth: dict[str, Any] | None=None, swagger_ui_parameters: dict[str, Any] | None=None) -> HTMLResponse` (`fastapi/openapi/docs.py:40-194`); `get_redoc_html(*, openapi_url: str, title: str, redoc_js_url="https://cdn.jsdelivr.net/npm/redoc@2/bundles/redoc.standalone.js", redoc_favicon_url="https://fastapi.tiangolo.com/img/favicon.png", with_google_fonts: bool=True) -> HTMLResponse` (`:197-298`); `get_swagger_ui_oauth2_redirect_html() -> HTMLResponse` (`:301-389`). Required URL/title parameters have no defaults. Swagger helper merges caller parameters over a copy of `swagger_ui_default_parameters`; serializes values and escapes `<`, `>`, `&` in embedded JSON. ReDoc conditionally includes Google Fonts. `swagger_ui_default_parameters` is a public mutable literal with keys `dom_id`, `layout`, `deepLinking`, `showExtensions`, and `showCommonExtensions` (`docs.py:22-37`).
- `FastAPI.openapi(self) -> dict[str, Any]` checks route version and `openapi_schema`, calls `get_openapi(...)` when absent/stale, stores the generated value and version, and returns the cached mapping (`fastapi/applications.py:1070-1103`). `setup()` registers `/openapi.json` (or configured URL), `/docs`, OAuth redirect, and `/redoc` only when the respective URLs are enabled; OpenAPI/docs routes are omitted from schema. The OpenAPI handler adds a root-path server to a shallow document copy when configured, so request root paths must not accumulate in the cached schema (`applications.py:1105-1158`). Constructor controls include `openapi_url`, `docs_url`, `redoc_url`, `openapi_tags`, `openapi_version`, `openapi_external_docs`, `servers`, `root_path_in_servers`, OAuth redirect/init settings, Swagger parameters, `separate_input_output_schemas`, and `webhooks` (`applications.py:199-222, 407-431, 709-765, 893-948`).
- The 35 pending model classes in `fastapi.openapi.models` have Pydantic-generated constructors (the source declares no custom `__init__`); use reflected signatures from `runtime-api-surface-standard.json` rather than inventing source signatures. The `Example` TypedDict is the exception to treating these as BaseModel constructors; its signature is not reflected. `SchemaOrBool`, `SchemaType`, and `SecurityScheme` are type-alias values, not model constructor calls. `BaseModelWithConfig` sets `extra="allow"`; `Reference` directly subclasses `BaseModel`; `Example` declares `total=False` and Pydantic extra allow. `Schema.model_rebuild()`, `Operation.model_rebuild()`, and `Encoding.model_rebuild()` resolve forward references (`models.py:433-435`).
- Source-level Pydantic aliases that need output/input probes include `Reference.ref -> "$ref"`; `PathItem.ref -> "$ref"`; `Schema.schema_ -> "$schema"`, `vocabulary -> "$vocabulary"`, `id -> "$id"`, `anchor -> "$anchor"`, `dynamicAnchor -> "$dynamicAnchor"`, `ref -> "$ref"`, `dynamicRef -> "$dynamicRef"`, `defs -> "$defs"`, `comment -> "$comment"`, `not_ -> "not"`, `if_ -> "if"`, `else_ -> "else"`; `MediaType.schema_` and `ParameterBase.schema_ -> "schema"`; `Parameter.in_ -> "in"`; `SecurityBase.type_ -> "type"`; and `APIKey.in_ -> "in"`. These are Pydantic model aliases, distinct from manifest import-alias references. `Schema.example` carries a `typing_extensions.deprecated` annotation directing users to `examples` (`models.py:198-204`). Separately, the schema field `Schema.deprecated` is a normal OpenAPI data field, not a Python deprecation. The manifest has no model alias/deprecation refs for these facts; only `generate_operation_id` has a deprecation ref among the pending OpenAPI rows.
- No FastAPI error-contract refs are recorded for the pending OpenAPI rows. `get_openapi` does not catch errors from `OpenAPI(**output)`; malformed metadata/model input can therefore expose Pydantic validation failures. Upstream `tests/test_openapi_schema_type.py` confirms `Schema(type=True)` raises a validation error (`ValueError` subclass in Pydantic) while valid scalar/list/None values are accepted. Duplicate operation IDs and deprecated `generate_operation_id` are the explicit warning cases identified above.

### Current mappings: limits on claims

- The 241 model rows all link to the documentation-fixture design `fastapi.docs.reference-openapi-models` (`mapping_status: candidate`; selectors `python.import_path`, `python.signature`, `python.attribute_value`, `openapi.document`). This design link is not executable coverage. Only three pending model classes have direct workflow refs, all signature-only: `Info`, `OpenAPI`, and `Schema` in `direct-api-reference-wave.yaml`.
- The three docs functions plus `swagger_ui_default_parameters` link to `fastapi.docs.reference-openapi-docs` as a candidate documentation design. None has direct `input_workflow_refs`. HTTP recipes currently validate app/helper routes; they do not establish direct symbol import identity.
- `get_openapi` has two direct workflow cases as noted. `generate_operation_id` has two warning-capturing direct call cases; none of the pending OpenAPI symbols has `identity_workflow_refs`.
- Existing `openapi.document` pointers are useful but partial: e.g. docs interface selects `/info`, `/paths`, `/tags`, callback subtrees, and split schemas; webhook recipes select `/webhooks`; security recipes select selected `/components/securitySchemes` and operation `/security`; route/model recipes select selected `/components/schemas`. These document projections do not cover all OpenAPI fields, model input behavior, aliases, errors, direct identity, or the complete `get_openapi` argument contract.
- No live source/target parity result was inspected or asserted in this review. Input recipes and fixture-design mappings are stimulus/selector plans only.

## Unresolved points

1. Whether all 247 pending public module symbols are intended for the supported runtime API or whether some candidates should be reviewed out. Atlas discovery/source classification is not the support contract.
2. Exact Pydantic-reflected signatures and `model_fields` metadata for every pending model class/field, including TypedDict `Example`, union alias import behavior, forward-reference introspection, `extra="allow"`, required-vs-nullable distinctions, and alias validation mode.
3. Exact Pydantic `ValidationError` message/location and serialization/error behavior through `get_openapi`; project currently has no FastAPI error-contract refs for these rows.
4. Whether to preserve mutable identity of `swagger_ui_default_parameters`, its shallow-copy/update behavior, and each generated helper's exact HTML/response body contract as direct public APIs.
5. How app cache invalidation interacts with all router route-version mutations and custom `openapi()` overrides; current recipes cover selected mutations and request root-path cases only.
6. The existing `FastAPI.openapi` reviewed slice and broad reference fixture do not yet resolve constructor parameter semantics for the full OpenAPI setting surface. Route-level docs tests do not substitute for direct `FastAPI.openapi` or model interface checks.
