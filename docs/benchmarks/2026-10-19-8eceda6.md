# Seven-workload direct-ASGI benchmark at `8eceda6`

Run completed 2026-10-19 at 04:04 UTC against FastAPI 0.141.1 and Starlette
1.6.0, with FastAPI-RS at `8eceda6f867de40cd04eaa71e62270a556fd2a3e` and
Starlette-RS at `4139a72449bf5751e8902fb1c7175ee7f191d338`. The seven
identity-checked parity gates passed all 45 selected observations before
timing. This is a narrow direct-ASGI benchmark result, not a full API parity
claim.

## Workloads and results

Per-request latency measures only `await app(scope, receive, send)`. It
includes the public Python facade, PyO3 boundary, Rust implementation,
FastAPI validation or serialization used by the workload, and captured ASGI
sends. It excludes interpreter startup, app construction, request scope and
callback setup, correctness checks, HTTP server startup, clients, and
network. Ratios divide FastAPI-RS latency by FastAPI latency.

| Workload | Parity | FastAPI median / p95 (µs) | FastAPI-RS median / p95 (µs) | Ratio median / p95 |
| --- | ---: | ---: | ---: | ---: |
| `fastapi.async-nested-distinct-query-aliases.asgi` | 2/2 | 525.479 / 687.750 | 827.479 / 1,094.875 | 1.575x / 1.592x |
| `fastapi.async-nested-two-query.asgi` | 2/2 | 456.729 / 1,251.792 | 951.875 / 2,130.333 | 2.084x / 1.702x |
| `fastapi.first-slice.chunked-body-asgi` | 13/13 | 300.854 / 475.542 | 453.020 / 777.375 | 1.506x / 1.635x |
| `fastapi.first-slice.invalid-asgi` | 13/13 | 319.854 / 572.291 | 561.271 / 952.000 | 1.755x / 1.663x |
| `fastapi.first-slice.valid-asgi` | 13/13 | 155.041 / 335.084 | 391.958 / 2,430.500 | 2.528x / 7.253x |
| `fastapi.large-response-model.asgi` | 1/1 | 922.542 / 1,501.375 | 1,090.250 / 1,629.875 | 1.182x / 1.086x |
| `fastapi.request.repeated-sequence-query.asgi` | 1/1 | 210.958 / 367.666 | 316.021 / 587.375 | 1.498x / 1.598x |

FastAPI-RS median and p95 latency were higher in all seven workloads. The
median ratios range from 1.182x to 2.528x; p95 ratios range from 1.086x to
7.253x. The harness retains raw samples and per-workload summaries. No
aggregate score or performance budget is applied. These results show slower
latency for these cases on this machine; they do not establish a general
performance conclusion for other routes, workloads, Python versions, or
hardware. The Starlette control, where declared, is contextual and is not
subtracted from either FastAPI measurement.

## Reproduction

Use the pinned source checkouts and isolated environments, then run:

```sh
RUSTC_WRAPPER= CARGO_NET_OFFLINE=true UV_CACHE_DIR=target/benchmark-uv-cache \
  make benchmark-suite \
    FASTAPI_SOURCE=/path/to/fastapi-at-95f8322 \
    STARLETTE_SOURCE=/path/to/starlette-at-4f250d6 \
    STARLETTE_RS_SOURCE=/path/to/starlette-rs-at-4139a724
```

Afterward, `make benchmark-contract-check` verifies the workload declarations
and current saved suite references. The report applies to this revision,
identity set, host, and seven direct-ASGI scenarios. It does not establish
full FastAPI compatibility or performance parity.
