## Measurement boundary and limits

The timer includes `app.openapi_schema = None` and the public
`FastAPI.openapi()` call. App construction, route and dependency registration,
module startup, and observation projection are outside the timer. The target
measurement includes the public Python facade, PyO3 conversion, Rust execution,
and OpenAPI generation. Each subject used five warmups and 100 samples on one
host. No Starlette control is included because standalone Starlette does not
implement FastAPI dependency injection or OpenAPI generation.
