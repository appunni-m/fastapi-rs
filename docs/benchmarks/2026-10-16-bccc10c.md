# First-slice direct-ASGI baseline at `bccc10c`

Measured on 2026-10-16 with FastAPI-RS source `bccc10c58b96c150de67aa7215d05738d8f5a63e`
and pinned Starlette-RS source `4139a72449bf5751e8902fb1c7175ee7f191d338`.
The isolated oracle identified FastAPI 0.141.1 at source
`95f8322ee1dcda7ceace7b1c4f6c9915b36d748f` and Starlette 1.6.0 at source
`4f250d6b814587e20c5365f0a5f0c4d42bcb929f`. The live thirteen-case parity
gate passed 13/13 before timing.

## Workload and environment

The workload is `fastapi.first-slice.valid-asgi`, case
`fastapi.first-slice.create-item-valid`, from
`benchmarks/workloads/first-slice-valid-asgi.yaml`. It uses generated input
`tests/fixtures/inputs/parity/first-asgi-request.json` (SHA-256
`f937e7552eb473629234576db598707748fe0a6570e5b3982022af21d4d86fbe`). The
workload declaration SHA-256 is
`fcc07446d1bc4e60a9375319a048736690647625ce6fb905de6621d11901177a`.

The run used CPython 3.12.13 on macOS 15.7.7 arm64 with 12 reported CPUs,
Rust/Cargo 1.98.1, Cargo's release profile, and `pyo3/extension-module`.
FastAPI 0.141.1 and FastAPI-RS shared Pydantic 2.13.4, pydantic-core 2.46.4,
AnyIO 4.12.1, and the remaining locked runtime packages.

Each subject used 50 warmups and 1,000 measured samples over five rounds.
Per-request latency times only `await app(scope, receive, send)`: it includes
the Python facade, PyO3/native dispatch, application work, validation, response
serialization, and captured ASGI sends. It excludes app construction,
interpreter startup, scope/event setup, HTTP client, server, and network.
Sequential request-loop throughput also includes per-call setup, response
observation, correctness checks, and loop bookkeeping. The Starlette control
is contextual and is not subtracted.

## Results

Latency is in microseconds. The ratio is FastAPI-RS divided by FastAPI.

| Subject | Median | p95 | Mean | Request-loop throughput |
| --- | ---: | ---: | ---: | ---: |
| FastAPI 0.141.1 | 161.146 | 259.917 | 174.923 | 5,568.03 requests/s |
| FastAPI-RS | 193.937 | 360.000 | 217.086 | 4,515.69 requests/s |
| Starlette 1.6.0 control | 5.250 | 5.500 | 5.451 | 139,759.96 requests/s |

FastAPI-RS measured 1.203x FastAPI median latency and 1.385x p95 latency on
this valid-request case. Its request-loop rate was lower. This is one
direct-ASGI workload only; it is not a full-suite performance claim or proof
of broader parity.
