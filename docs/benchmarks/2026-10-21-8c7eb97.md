## Measurement boundary

Each timed subject used the same input action and passed its identity-checked parity gate first. Per-request latency times only `await app(scope, receive, send)`. It includes FastAPI request handling on the oracle; the FastAPI-RS facade, PyO3 conversion and native execution on the target; ASGI dispatch; response creation; and captured response sends. It excludes interpreter startup, app and route setup, per-request ASGI callback construction, response signature extraction, correctness checks, loop bookkeeping, HTTP server work, and network or HTTP client overhead. Samples ran sequentially with concurrency 1. Ratios are FastAPI-RS divided by FastAPI; values above 1.0 indicate higher FastAPI-RS latency.

Each subject used 50 warmups and 5 rounds of 200 requests, retaining all 1,000 raw latency samples per workload. This is one run on one host; operating-system scheduling and outliers can affect tail latency.
