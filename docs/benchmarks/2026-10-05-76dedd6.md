# Direct ASGI measurements at 76dedd6

Measured on 2026-10-05 at FastAPI-RS commit
`76dedd638d1817342d77741dab28bb641ff8d0b5`. All seven declared workload
gates passed fresh live source/target parity and untimed response checks.
This is evidence for these selected workloads; complete API parity remains
unfinished.

## Environment and boundary

macOS 15.7.7, arm64, 12 reported CPUs; CPython 3.12.13; Rust 1.98.1;
Cargo release profile with `pyo3/extension-module`, without fault injection
or coverage instrumentation. FastAPI 0.141.1 (`95f8322`), Starlette 1.6.0
(`4f250d6`), Starlette-RS `b4c8a65`, Pydantic 2.13.4 and
pydantic-core 2.46.4 were identity checked.

Each subject used 50 warmups and five rounds of 200 sequential samples.
Latency times `await app(scope, receive, send)`, including native dispatch,
validation and response serialization. Construction, per-call setup,
client/server and network costs are excluded. Raw samples and wider request
loop throughput remain in the ignored artifacts. The Starlette control is
contextual; its cost is never subtracted.

## Observations

Latency is in microseconds. Ratios are FastAPI-RS divided by FastAPI;
values below 1 mean lower measured latency.

| Workload | FastAPI median | FastAPI-RS median | Median ratio | p95 ratio |

| Nested dependencies, two query fields | 422.52 | 312.60 | 0.740 | 0.726 |
| First slice, chunked body | 135.38 | 50.75 | 0.375 | 0.436 |
| First slice, invalid request | 144.62 | 227.85 | 1.575 | 1.205 |
| First slice, valid request | 134.96 | 47.38 | 0.351 | 0.360 |

Invalid-request and large-response serialization costs remain optimization
work. This run does not establish network throughput, concurrent behavior,
cross-machine performance, or performance of later revisions.
