## Measurement boundary

Each subject used 50 warmups and five rounds of 200 sequential samples, keeping
all 1,000 measured per-request latency samples. The timer covers only
`await app(scope, receive, send)`. It includes FastAPI request processing or
FastAPI-RS's public Python facade, PyO3 conversion, Rust implementation,
Pydantic work, and Starlette-RS dispatch. It excludes interpreter startup,
application and route setup, scope and callback construction, response
observation and correctness checks, loop bookkeeping, HTTP server work, and
network or client overhead.
