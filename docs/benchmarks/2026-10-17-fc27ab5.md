# First-slice direct-ASGI measurement at `fc27ab5`

Measured on 2026-10-17 against FastAPI 0.141.1 at source
`95f8322ee1dcda7ceace7b1c4f6c9915b36d748f`, Starlette 1.6.0 at source
`4f250d6b814587e20c5365f0a5f0c4d42bcb929f`, FastAPI-RS
`fc27ab530be20fbac83f093db467c9129609bf5d`, and pinned Starlette-RS
`4139a72449bf5751e8902fb1c7175ee7f191d338`. The identity-checked, selected
thirteen-case parity gate passed 13/13 before timing.

## Workload and environment

The workload is `fastapi.first-slice.valid-asgi`, case
`fastapi.first-slice.create-item-valid`, from
`benchmarks/workloads/first-slice-valid-asgi.yaml`. It uses
`tests/fixtures/inputs/parity/first-asgi-request.json` (SHA-256
`f937e7552eb473629234576db598707748fe0a6570e5b3982022af21d4d86fbe`). The
workload declaration SHA-256 is
`fcc07446d1bc4e60a9375319a048736690647625ce6fb905de6621d11901177a`.

The run used CPython 3.12.13 on macOS 15.7.7 arm64, Rust/Cargo 1.98.1, Cargo's
release profile, and the `pyo3/extension-module` feature. FastAPI and FastAPI-RS
shared Pydantic 2.13.4, pydantic-core 2.46.4, AnyIO 4.12.1, and the other
locked runtime packages.

Each subject used 50 warmups and 1,000 measured samples over five rounds of 200.
Per-request latency times only `await app(scope, receive, send)`: it includes
the Python facade, PyO3/native dispatch, application work, validation, response
serialization, and captured ASGI sends. It excludes app construction,
interpreter startup, scope/event setup, HTTP client, server, and network.
Sequential request-loop throughput also includes per-call setup, response
observation, correctness checks, and loop bookkeeping. The Starlette control is
contextual and is not subtracted.

## Results

Latency is in microseconds. Ratios are FastAPI-RS divided by FastAPI.

| Subject | Median | p95 | Mean | Request-loop throughput |
| --- | ---: | ---: | ---: | ---: |
| FastAPI 0.141.1 | 137.334 | 395.417 | 220.280 | 4,447.40 requests/s |
| FastAPI-RS | 155.604 | 179.625 | 160.616 | 6,111.17 requests/s |
| Starlette 1.6.0 control | 5.209 | 5.375 | 5.254 | 144,413.03 requests/s |

FastAPI-RS measured 1.133x FastAPI median latency and 0.454x p95 latency on
this run; its sequential request-loop rate was higher. These are mixed,
single-machine observations for one valid request, not a full-suite performance
claim or proof of broader parity.
