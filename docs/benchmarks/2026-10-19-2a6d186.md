## Workload and environment

The workload is `fastapi.first-slice.valid-asgi`, case
`fastapi.first-slice.create-item-valid`, from
`benchmarks/workloads/first-slice-valid-asgi.yaml`. Its generated input SHA-256
is `f937e7552eb473629234576db598707748fe0a6570e5b3982022af21d4d86fbe`; the
workload declaration SHA-256 is
`fcc07446d1bc4e60a9375319a048736690647625ce6fb905de6621d11901177a`.

Per-request latency times only `await app(scope, receive, send)`. It includes
the Python facade, PyO3 dispatch, FastAPI-RS behavior, validation, response
serialization, and captured ASGI sends. It excludes application construction,
interpreter startup, scope and callback setup, HTTP client, server, and network.
The separate request-loop throughput measure includes setup, response
observation, correctness checks, and loop bookkeeping. The Starlette control is
contextual and is not subtracted from FastAPI measurements.

The run used CPython 3.12.13 on macOS 15.7.7 arm64. The harness reported 12
logical CPUs and processor `arm`, without a specific processor model. Rust and
Cargo 1.98.1 built the release profile with `pyo3/extension-module`. The oracle
and target shared Pydantic 2.13.4, pydantic-core 2.46.4, and AnyIO 4.12.1. Each
subject had 50 warmups and 1,000 measured samples over five rounds at
concurrency one.

## Results

Latency is in microseconds. Ratios divide FastAPI-RS by FastAPI.

| Subject | Median | p95 | Mean | Request-loop throughput |
| --- | ---: | ---: | ---: | ---: |
| FastAPI 0.141.1 | 134.708 | 147.625 | 138.272 | 7,033.86 requests/s |
| FastAPI-RS | 157.708 | 216.250 | 170.225 | 5,767.48 requests/s |
| Starlette 1.6.0 control | 5.291 | 5.416 | 5.278 | 144,082.69 requests/s |

FastAPI-RS measured 1.171x FastAPI median latency and 1.465x p95 latency for
this request. The earlier first-slice report measured 1.238x and 1.979x,
respectively. The changes between those revisions did not optimize the hot
request path, so the difference is a revision-specific measurement change, not
evidence of an optimization. No performance budget was applied; performance
parity remains unproven beyond this single workload.
