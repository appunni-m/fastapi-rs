The direct-ASGI timer measures `await app(scope, receive, send)` per request.
App construction, interpreter startup, and per-call ASGI scope/callback setup
are outside the timer. FastAPI-RS timings include the public Python facade,
PyO3 conversion, Rust implementation, Pydantic work, and Starlette-RS dispatch
as one consumer path. Each subject used 50 warmups and five rounds of 200
sequential samples. This is a single-machine direct-ASGI comparison, not a
loopback HTTP-server result.

## Direct-ASGI results

Latency values are median / p95 microseconds. Ratios are FastAPI-RS divided by
FastAPI; values above 1.0x mean FastAPI-RS took longer on this host.

| Workload | FastAPI median / p95 | FastAPI-RS median / p95 | Median / p95 ratio | Parity |
| --- | ---: | ---: | ---: | ---: |
| Async nested dependencies, distinct query aliases | 490.1 / 526.2 µs | 726.0 / 845.7 µs | 1.481x / 1.607x | 2/2 |

results describe only the listed inputs on this host; they do not establish a
global performance claim or complete FastAPI compatibility.
