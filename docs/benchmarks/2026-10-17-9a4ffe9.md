Measured on 2026-10-17 against FastAPI 0.141.1 at source
`95f8322ee1dcda7ceace7b1c4f6c9915b36d748f`, Starlette 1.6.0 at source
`4f250d6b814587e20c5365f0a5f0c4d42bcb929f`, FastAPI-RS
`9a4ffe9114345dc26e3576610a4adce80d6d2e1b`, and pinned Starlette-RS
`4139a72449bf5751e8902fb1c7175ee7f191d338`. All seven declared workloads

This is a current measurement for the listed workloads, not a claim of full

## Workloads and environment

The suite is the reviewed seven-workload set declared in
`benchmarks/workloads/`. It was run against manifest SHA-256
`b6affa30e49850ef948e2d11e2116f1f85a0da8ff82287aafdde689b37b539fc`.

Both subjects used CPython 3.12.13 on macOS 15.7.7 arm64 with 12 logical CPUs.
FastAPI and FastAPI-RS shared Pydantic 2.13.4, pydantic-core 2.46.4, AnyIO
4.12.1, and the other pinned runtime packages. The target used Cargo and rustc
1.98.1, Cargo's release profile, and `pyo3/extension-module`. The target
extension SHA-256 is
`1b9af8b1f749f3bac1c62fb49071c331fed9c49db688a8bd68cb3475584f4309`; the
target binary SHA-256 is
`7e3b08c29c09cac89fdfae2754d5125a0977ea8505f008489963cd7db47072e6`.
The run did not capture a CPU model, memory size, or power mode.

Each subject used 50 warmups and 1,000 measured samples in five rounds of 200,
at concurrency 1. Per-request latency measures only `await app(scope, receive,
send)`, including the FastAPI-RS Python facade, PyO3 conversion, Rust behavior,
Pydantic work, and Starlette-RS dispatch. It excludes interpreter startup, app
construction, ASGI scope/callback construction, HTTP server, and network.
Sequential request-loop throughput includes per-call setup, response
observation, correctness checks, and loop bookkeeping. Raw latency samples are
retained in the ignored workload receipts; p95 is shown as a spread measure,
and no confidence intervals were calculated. Starlette controls are
contextual where declared and are not subtracted from FastAPI timings.

global speedup claim or identify component-level costs.

## Receipts and reproduction

The completed suite receipt is
`benchmark-results/suite-20261017T141404Z-b55c85fb-87bb-4dab-be98-3de35d31b6d4.json`
(run ID `b55c85fb-87bb-4dab-be98-3de35d31b6d4`, SHA-256

binds all seven workload receipts by SHA-256. Each workload receipt records
its parity comparison receipt, raw samples, workload and input digests, build,
and runtime identity. Receipts and generated parity inputs are ignored by Git
as project policy requires; the paths and hashes above identify this local
run but are not checked-in artifacts.

The suite and current workload/result references passed
`make benchmark-contract-check` for all seven declared workloads.

To reproduce with the pinned clean source trees:

```sh
UV_OFFLINE=1 RUSTC_WRAPPER= CARGO_BUILD_RUSTC_WRAPPER= \
  make benchmark-suite \
  STARLETTE_RS_SOURCE=/private/tmp/fastapi-rs-starlette-rs-4139
make benchmark-contract-check \
  STARLETTE_RS_SOURCE=/private/tmp/fastapi-rs-starlette-rs-4139
```

The offline run requires the locked packages and toolchain already to be
available locally. Broader FastAPI compatibility work remains incomplete.
