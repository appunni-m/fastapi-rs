## Measurement boundary

Each target/oracle pair uses the same input action and must pass its identity-checked parity gate before timing. The measured per-request latency includes FastAPI request handling on the oracle; FastAPI-RS behavior, its Python facade and PyO3 conversions on the target; ASGI dispatch; response creation; and captured response sends. It excludes interpreter/module startup, app construction and route registration, ASGI callback construction, response signature extraction, correctness checks, loop bookkeeping, HTTP server startup, network, and an HTTP client. Concurrency is 1. The bare-Starlette control is contextual and is not subtracted from FastAPI timings.

Each subject had 50 warmups and 5 rounds of 200 requests, retaining all 1,000 raw per-request latency samples. Ratios are FastAPI-RS divided by FastAPI; lower than 1.0 means lower target latency.
