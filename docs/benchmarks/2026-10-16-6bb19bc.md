# First-slice direct-ASGI baseline at `6bb19bc`

Measured on 2026-10-16 using FastAPI-RS `6bb19bcffea5698e460a5b7e9283921ccc9b51ff`
and the pinned Starlette-RS `4139a72449bf5751e8902fb1c7175ee7f191d338`.
FastAPI 0.141.1 and Starlette 1.6.0 were identity-checked as the oracle.
The current 13-case first-slice parity gate passed 13/13 before timing.

## Workload and environment

The workload is `fastapi.first-slice.valid-asgi`, case
`fastapi.first-slice.create-item-valid`, from
`benchmarks/workloads/first-slice-valid-asgi.yaml`. Its generated input is
`tests/fixtures/inputs/parity/first-asgi-request.json`, SHA-256
`f937e7552eb473629234576db598707748fe0a6570e5b3982022af21d4d86fbe`.
The workload declaration SHA-256 is
`fcc07446d1bc4e60a9375319a048736690647625ce6fb905de6621d11901177a`.
The timing boundary, shared environment, and correctness gate are defined in
[`PARITY_BENCHMARK_PLAN.md`](../PARITY_BENCHMARK_PLAN.md#first-executable-lane).

The run used CPython 3.12.13 on macOS 15.7.7 arm64, Rust/Cargo 1.98.1, Cargo's
release profile, and `pyo3/extension-module`. FastAPI 0.141.1 source was
`95f8322ee1dcda7ceace7b1c4f6c9915b36d748f`; Starlette 1.6.0 source was
`4f250d6b814587e20c5365f0a5f0c4d42bcb929f`. Pydantic 2.13.4,
pydantic-core 2.46.4, AnyIO 4.12.1, and the remaining shared runtime packages
match the pinned target/oracle profiles.

Each subject used 50 warmups and 1,000 measured samples over five rounds.
Per-request latency includes the ASGI call, Python facade, PyO3/native dispatch,
validation, response serialization, and captured ASGI sends. It excludes app
construction, interpreter startup, scope/callback setup, HTTP client, server,
and network. Request-loop throughput includes per-call setup, observation,
correctness checks, and loop bookkeeping. The Starlette control is contextual
only.

## Results

Latency is in microseconds. Ratios divide FastAPI-RS by FastAPI.

| Subject | Median | p95 | Mean | Request-loop throughput |
| --- | ---: | ---: | ---: | ---: |
| FastAPI 0.141.1 | 134.875 | 156.750 | 137.946 | 7,053.95 requests/s |
| FastAPI-RS | 172.208 | 578.292 | 241.425 | 4,054.87 requests/s |
| Starlette 1.6.0 control | 5.208 | 6.166 | 5.265 | 144,440.83 requests/s |

FastAPI-RS measured 1.277x FastAPI median latency and 3.689x p95 latency on
this valid-request case. Its request-loop rate was lower. This is a single
workload baseline, not a full-suite or cross-machine performance claim; the
large p95 gap needs follow-up measurements before drawing broader conclusions.
