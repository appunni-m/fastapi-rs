# Security policy

## Report a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/appunni-m/fastapi-rs/security/advisories/new)
for FastAPI-RS vulnerabilities when that repository feature is enabled. Its
enablement could not be confirmed from the source checkout. GitHub only offers
the private form when the repository has enabled the feature; see
[GitHub's private reporting guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
If the form is unavailable, open a public issue only to request a private
reporting channel; do not include vulnerability details, exploit code,
credentials, or affected private data in that issue. Do not disclose an
unpatched vulnerability in a public issue or discussion.

Include the affected package and version or commit, the relevant environment,
impact, and reproduction details once a private channel is established. Do not
send real credentials or private user data.

## Supported versions and response

The project is alpha; no supported-version window or response and remediation
timeline is published. Public package availability also remains unverified.
